# rhubarb-geek-nz/EnvironmentalConcerns
Environment cmdlet for PowerShell

## Expand-EnvironmentVariables

Calls [System.Environment.ExpandEnvironmentVariables](https://learn.microsoft.com/en-us/dotnet/api/system.environment.expandenvironmentvariables) with the input string and outputs the string result.

```
Expand-EnvironmentVariables [-InputString] <string> [<CommonParameters>]
```
